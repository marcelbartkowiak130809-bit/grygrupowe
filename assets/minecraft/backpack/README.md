# Minecraft textures

Unmodified PNG textures from Minecraft Java Edition 1.21.4, downloaded from
https://assets.mcasset.cloud/1.21.4/assets/minecraft/textures/ on 2026-11-17.
File names match their original block/ or item/ names.
Exception: tnt.png uses the original block/tnt_side.png, renamed for inventory use.
Further inventory aliases: piston = block/piston_side; pumpkin = block/pumpkin_side;
oak_slab = block/oak_planks; composter = block/composter_side;
light_weighted_pressure_plate = block/gold_block; compass = item/compass_16;
decorated_pot = entity/decorated_pot/decorated_pot_side;
end_portal = entity/end_portal. These are the original, unmodified PNG bytes.
Minecraft assets belong to Mojang / Microsoft. This is an unofficial fan-made
browser minigame, not a Mojang product. No generated replacement artwork is used.
The tall lava texture is Minecraft's original animated sprite sheet; CSS steps
through its frames (static when reduced motion is enabled). Icons intentionally
use pixelated rendering. Textures are served locally, not via runtime hotlinks.
