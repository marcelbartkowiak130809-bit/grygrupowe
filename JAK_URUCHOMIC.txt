UDOWODNIJ! - URUCHAMIANIE

LOKALNIE NA WINDOWS
1. Kliknij dwa razy plik URUCHOM_GRE.bat.
2. Zostaw otwarte okno terminala podczas grania.
3. Gra otworzy sie pod adresem http://127.0.0.1:49322/

Nie otwieraj index.html bezposrednio przez dwuklik.
Przegladarki blokuja wtedy importy modulow JavaScript uruchamiane z adresu file://.

PUBLIKACJA
Mozesz wrzucic caly folder bez budowania na itch.io, Netlify albo GitHub Pages.
Na opublikowanej stronie index.html uruchomi sie normalnie.

Projekt nie wymaga npm install ani npm run build.

POKOJE ONLINE MIEDZY ROZNYMI URZADZENIAMI
1. Otworz plik js/firebase-config.js.
2. Wklej konfiguracje swojej aplikacji Web z Firebase Console.
3. W Firebase wlacz Authentication -> Email/Password oraz Anonymous.
4. Wlacz Realtime Database.
5. Wklej zawartosc firebase-database-rules.json w zakladce Realtime Database -> Rules.

LUCKY SPIN - JEDNORAZOWE WDROZENIE BACKENDU
Lucky Spin wymaga Firebase Functions, bo losowanie i blokada 24 godzin sa wykonywane
na serwerze. W katalogu projektu uruchom:
1. firebase login
2. firebase deploy --only functions,database

Jesli Firebase CLI nie jest zainstalowane, zainstaluj je poleceniem:
npm install -g firebase-tools
Backend pobierze zaleznosci z katalogu functions przy wdrozeniu. Po publikacji
odswiez strone; bez wdrozonej funkcji przycisk pokazuje komunikat o braku serwera.

Bez Firebase gra dziala jako lokalne demo. Pokoje sa wtedy widoczne tylko
miedzy kartami tej samej przegladarki, a nie na telefonach znajomych.
